# 評価 context

目標、評価期間、自己評価、評価者の評価と版を所有する。承認の正本はSystem、在籍と会社上の判断資格はCompanyに置く。依存方向は評価 → Company → Systemとする。

提出は内容の変更不能な版とSystem案件を同じtransactionで作る。判断はCompanyで現在の資格を再検査し、Systemの判断と評価の状態・履歴を同じtransactionで保存する。管理権限を評価者の資格の代用にしない。

画面は追加しない。HTTP APIとMCPを提供する。変更には期待版、冪等キー、理由を要求し、確定後は変更しない。評価値は運用上の記録であり、給与・処遇の計算や自動決定を行わない。
